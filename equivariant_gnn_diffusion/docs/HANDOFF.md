## What this project is

Generate new grain-boundary patterns for a 2D bidisperse particle system using a
two-stage diffusion pipeline:
- **Stage 1** (`map_generator.py`): small image diffusion over 64×64 coarse |ψ6| maps —
  generates the mesoscale grain LAYOUT.
- **Stage 2** (`egnn.py` + `diffusion.py`): rotation-equivariant GNN diffusion over
  particle positions, conditioned on a ψ6 map — realises the layout as particles.

## Data layout and conventions (critical gotchas)

- `data/npy/*.npz`: 418 full boxes. Keys: pos (N,2), type, size, box_size.
- `data/patches/{train,val}/*.npz`: 1,508/164 patches of ~4,000 particles
  (regenerated by `make_patches.py`; N_TARGET=4000). Keys: pos (CoM-centred),
  node_scalars (N,9).
- **TYPE IS INVERTED**: type 0 = LARGE defect (diameter 1.4), type 1 = SMALL
  (diameter 1.0). Never trust the "obvious" convention. Derive defect masks from
  size (`sizes > 1.2`). node_scalars columns: 7 = size, 8 = type, 5 = ψ6 (freud).
- Composition: 50 defects / 10,050 particles per box.
- Real-data benchmarks (interior particles): mean |ψ6| ≈ 0.95–0.97, median NN
  distance ≈ 1.05, 6-coordination fraction ≈ 0.97. Real boundaries are SPARSE.

## Model/pipeline invariants (do not break these)

1. **Coordinates are normalised** by the checkpoint's `coord_scale` (currently 17.43).
   Everything inside diffusion runs in normalised units; multiply by coord_scale on
   output. Never change coord_scale when resuming a checkpoint.
2. **Noise schedule is `logsigma`** (`logsigma_beta_schedule` in diffusion.py) — a
   log-spaced noise-to-signal ladder [0.002, 60]. This was THE decisive fix (see
   REPORT §2.7). If you change patch size / coord_scale, rescale sigma_min so it stays
   below the normalised lattice jitter (~0.05 physical / coord_scale). Schedule +
   conditioning setup are stored in the checkpoint config; sampling reads them.
3. **CoM-free subspace everywhere**: data, noise, every reverse step, and the model's
   predicted eps are all CoM-projected. The model uses radial features (|x|, radial
   updates) that are only valid in the CoM-centred frame.
4. **Conditioning = identity (size, type as ±1 encodings, see
   `train_patched.identity_scalars`) + optionally a coarse ψ6 field value.** Never feed
   per-particle structural descriptors — they leak (REPORT §2.2).
5. Model input dim (`n_scalar_feats`) is 3 when field-conditioned, 2 otherwise;
   checkpoints are not interchangeable across this or across schedules.

## Diagnostic tools (use before guessing)

A scratchpad script (recreate if gone) proved invaluable — two probes:
1. **loss vs t**: eps-MSE at fixed t across the schedule. Healthy profile: low at the
   extremes, a hump in the ambiguous mid band (sigma ≈ lattice spacing, genuinely
   irreducible). If loss ≈ 1.0 in a band, that band is untrained/broken.
2. **diffuse–denoise**: noise a REAL patch to t_start, run the reverse process,
   measure |ψ6| of the result vs the original (use evaluate.py helpers). If order is
   destroyed from small t_start, the fine end of the schedule/model is broken; the
   largest order-preserving t_start tells you the trust region.
